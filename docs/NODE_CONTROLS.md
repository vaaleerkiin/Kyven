# Nuke control reference

[Documentation home](README.md) · [Visual node guide](NODES.md) · [Shared workflow](NUKE.md)

Captured from new nodes in Nuke 16.0v4 with factory model preferences and no inputs. No inference was run.

Generated by [document_nodes.py](../scripts/document_nodes.py). Rerun with `Nuke16.0.exe --nukex -i -t scripts/document_nodes.py` after changing controls.

Tables list visible editable controls and buttons. A control may be disabled until its input or mode is available. Context-dependent controls can appear after changing a mode; use the linked task guide for their behavior. Saved scripts and Model Manager defaults can differ from these factory values.

Choices: SAM 2.1 Tiny (4 GB); SAM 2.1 Small (6 GB, recommended for 8 GB); SAM 2.1 Base+ (8 GB, may require fallback); SAM 2.1 Large (12 GB+); HQ-SAM 2.1 Large Beta (12 GB+, fine detail). |

| **Key Frame** (`key_frame`) | 0 | Frame where the primary object prompts anchor video tracking. Choose a clear view of the subject. Tracking propagates from this frame within the selected range. |

| **+ Correction at Current Frame** (`add_correction`) | Action | Stores a correction at the current frame using its object prompts. Use on a frame where tracking drifts, then propagate again to incorporate the correction. |

| **New Cache Version** (`new_cache_version`) | Action | Switches to a new cache version so another pass can be stored separately. Earlier cache files remain on disk. |
