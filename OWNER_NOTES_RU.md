# Kyven — заметки владельца

Kyven — локальный набор инструментов для Nuke, ограниченный тремя рабочими направлениями:

- Segment создаёт базовую маску с помощью SAM 2;
- Refine превращает маску или trimap в мягкий альфа-канал с помощью ViTMatte;
- Inpaint удаляет отмеченную область с помощью LaMa.

Модели работают во внешнем локальном процессе, чтобы Nuke оставался отзывчивым. Исходные кадры
не отправляются во внешние сервисы. Результаты записываются в обычные файлы кэша и остаются
доступными без загруженной модели.

Приоритеты проекта: стабильная работа этих трёх инструментов, понятные ошибки, контролируемое
использование памяти, проверяемые загрузки моделей и безопасное управление кэшем.
